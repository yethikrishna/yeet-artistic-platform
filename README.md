## Overview

Yeet Artistic Platform is a revolutionary web platform for AI-powered artistic creation and creative community engagement. Built with a modern React + TypeScript + Vite stack and featuring stunning Framer Motion animations, Yeet provides artists with AI tools to enhance their creative workflow while building a community around AI-assisted art.

## Features

- **AI Artistic Creation** - AI-powered tools for generating and enhancing artistic content
- **Community Platform** - Share, discover, and collaborate on artworks with other creators
- **Stunning Animations** - Framer Motion for smooth, performant, and delightful page transitions
- **Client-Side Routing** - React Router DOM 6 for seamless single-page navigation
- **Beautiful Icons** - Lucide React for consistent, elegant iconography
- **Type-Safe** - Full TypeScript for reliable code and great DX
- **Blazing Fast** - Vite for instant HMR and optimized production builds
- **Multi-Platform Deployment** - Vercel and GitHub Pages ready
- **SEO Optimized** - Custom domain, sitemap, and meta tags for discoverability

## Tech Stack

| Layer | Technology |

## Quick Start

```bash
# Clone the repository
git clone https://github.com/yethikrishna/yeet-artistic-platform.git
cd yeet-artistic-platform

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
npm run vercel-build  # For Vercel

# Preview production build
npm run preview
```
